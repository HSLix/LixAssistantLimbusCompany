# 素材处理

1. 选取状态特征前先查询当前 Asset，确认是否已有类似标题、特色按钮或图案，按内容和语义用途复用。新增逻辑名应适度体现内容，避免无法检索的泛称；不为统一命名擅自批量改名旧 Asset。仅在确有需要时新增或归档移除。共享 Asset Library 影响其他 Session 和后续匹配，切换 Session 不会撤销；除专用新增／归档工具外，不改既有图片或标签。
   判断 Asset 是否存在、是否仍有图片及其当前内容，以本轮对话中的工具查询结果为依据；跨轮的素材树、目录和图片信息可能已变化，不能据此断言当前存在或不存在。缺少本轮依据时，先用 asset_tree 或 asset_directory 查询；权限不足、读取失败等工具错误只说明未能确认，不能当作素材不存在的证据；明确返回目标目录不存在时则可据此判断。
2. 匹配保留完整返回结果；多个命中不自动失败、不视为无目标，也不要求全部动作。业务 Step 决定选择和动作，有歧义时用 ctx.log(message, level="warning") 记录歧义及依据，不随意丢弃结果或认定完成。
3. 需要现场区域时获取当前截图，结合原图、坐标网格和同图 OCR 定位。截图会恢复并置前唯一游戏窗口，现场工具仅 Windows 可用。网格等辅助覆盖层不能进入模板或原始证据。
4. game_screenshot 附带完整 OCR，坐标为客户区像素；ocr_error 表示识别失败，不是没有文字。OCR 不支持韩文，分数不证明识别正确。素材尽量避免掺入文字以适应语言变化；必须含文字时可以保存，也应考虑 OCR 能否替代。
5. 保存前调用 preview_crop，检查区域标线图、干净裁剪图和同图匹配。区域不合适就重新预览；符合目标后只用该次 preview_id 调用 crop_asset 保存相同像素，不重新截图或猜测 ID。ID 失效就重新获取。同图匹配不证明跨状态可靠性；同名同哈希复用原图和原标签。
6. 按特征选方法：外观尺寸固定时考虑 observe.match_asset；缩放／透视形变时按需试 observe.match_feature；文字特征考虑局部 OCR，不认为某一种一定最好。接口和预处理以 action_contracts 为准：match_asset 原尺寸匹配，不自动套用 SIFT 增强；match_feature 在原始模板与截图两侧生成处理图，返回原图坐标。保存原始裁剪，不把实验放大／增强后的图直接当作普通匹配模板。当前页识别可用少量独特特征，随证据逐步改进。
7. 没有用户本轮明确要求，不得自行归档图片；默认调用 remove_asset 由宿主请求 feedback 确认，只有用户本轮明确要求归档该目标时才能传 explicit_user_request=true。拒绝、跳过、取消不授权，不自动重试；CLI 无反馈权限时必须已有明确要求。归档移除前确认逻辑名、具体哈希和理由，仅使用 remove_asset；仍有图片时保留目录，只移除对应标签；已无图片且仅剩本目录标签文件时清理标签文件与逻辑名目录；仍有子目录或其他文件时保留这些内容，不递归删除，查看工具返回的保留原因。工具失败时先检查原因，不假定已移除。总结实际保存或移除内容及尚未验证的适用状态。
8. 恢复归档使用 restore_asset(logical_name, sha)，sha 必须是完整 hash；恢复原逻辑名的最新归档原图和标签，不需要现场截图，归档保留。已有活跃图及标签不覆盖；工具失败不假定恢复成功。该工具与 remove_asset 同权限，Runtime 不可用。

## 临时识别 Step

- 必要时在当前工具允许范围创建仅使用 observe 动作的临时 Step，测试现有／新选特征在当前页面是否命中、是否误识别；不要添加点击、按键、拖拽或其他游戏控制输入。截图仍可能置前窗口。修改 Candidate 后按 `../validation-and-trial/SKILL.md` 完整校验发布，用明确版本独立试验，不执行可变 Candidate。
- 使用时读取 `../workflow-conventions/SKILL.md` 的类型与调用契约；观察 Step 输出实际匹配／OCR 证据。需要稳定性证据时可有限观察多帧；当前页单次命中、同图自匹配或没有其他页面负例，都不能证明跨场景稳定，不为收集负例擅自改变游戏进度。
- 用完可考虑清理，但“临时”不等于删除授权。仅在用户明确要求且当前启用 delete_component 时，先检查源码、Manifest 登记及所有调用方并说明影响，按工具专用人工确认删除 Candidate 单个文件；拒绝／跳过不重试。工具不清登记或引用，按本次授权用 edit 同步，再完整校验发布；已发布识别试验版本仍保留。无删除权限时如实说明保留，不绕过工具或修改历史。
- 需要更新素材引用时同步 Candidate；验证与报告统一遵循验证指导，保留当前图片／日志，不把识别试验当作游戏业务验收。
