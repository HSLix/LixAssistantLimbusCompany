# LALC 用户指南

LALC 可以在 Windows 上按预先编写的工作流操作《边狱公司》。每个工作流负责一组特定任务。第一次使用时，你需要准备 Windows 程序包，以及与你要运行的任务配套的分享包（资源包）。

## 解压并打开

1. 把下载的 Windows x64 压缩包**全部解压**到一个文件夹。
2. 在解压后的文件夹里双击 **LALC.exe**。以后更新程序时，用户设置和运行记录仍存放在独立的 `%LOCALAPPDATA%\LALC` 目录。
3. 如需切换语言，打开 **通用设置 → 界面语言** 选择，再点「保存并重新加载整个应用」。

文件名含 `with-agent` 的包自带运行 [Agent（AI 助手）][agent] 所需的 [pi][pi] 程序。只运行已有工作流时，选任一压缩包即可，也可以关闭「启用 User Agent」。准备使用 AI 修复时，选 `with-agent` 可以省去手动安装 pi 的步骤，模型服务仍需单独配置。

## 首次配置

无论是第一次下载，还是从 5.x 升级，都需要重新配置个性化设置。不过官方内置资源包提供了星光强化、饰品和主题卡包的倾向配置，可直接导入使用。

所以建议下载后完成以下配置再运行：
1. 罪人的编队和顺序设置，以及倾向的流派；
2. 镜牢配置的编队；
3. （可选）Agent 的 api key，然后打开启用 Agent，将会在工作流实在无法推进时让 Agent 介入修复工作流；

## 更新程序

首页显示 GitHub 最新发行公告和当前框架版本。程序启动时检查更新，也可以点「检查更新」。看到新版后，点「更新」开始下载，校验通过后点「重启并安装更新」。请先结束正在运行的任务。安装成功后，旧程序备份保存在安装目录旁边，目录名含 `.backup-`。

应用内更新从 GitHub 下载与已安装版本相同类型的包。你也可以打开 GitHub Release 手动下载任一 Windows 包。

「版本与更新」标题右侧提供 Mirror 酱、夸克网盘和 GitHub 入口。Mirror 酱图标带勾表示已保存 CDK，点击可直达 **通用设置 → 应用 → Mirror 酱 CDK**。在 Windows 上可提前点「设置」加密保存 CDK，也可以点「清空」移除。设置一栏提供 Mirror 酱项目页链接。

首页的「版本与更新」也会单独检查官方资源包。看到资源包有新版时，点「下载并预览」，核对工作流、素材和页面变更，再确认需要导入的内容。看过预览后，同一包会标为「已查看」，有需要时仍可再次预览。导入资源使用下节所述流程。

从 5.x 升级时，可用旧版的更新功能下载 `lalc.zip`，并确认执行迁移。迁移会替换原路径下的程序。旧版数据留在原位置，新版工作流通过分享包导入。全新安装请下载文件名带版本号的 Windows 包。

## 导入工作流

首次启动时，如果首页还没有可运行的任务，可以在「版本与更新」里点官方资源包的「下载并预览」，选择并导入所需内容。也可以从工作流提供者获取配套分享包。一个任务可能需要同时安装工作流版本（manifest）、识别游戏画面的图片（asset），以及用于配置任务的页面（page）。

如果程序包附有默认资源，且本机的资源和业务设置为空，首次打开首页会询问是否导入。确认后重新加载 LALC，再在首页选中导入的工作流版本。日后更新工作流及其他资源，请下载对应分享包，再手动导入。

1. 打开 **通用设置 → 分享 → 导入…**，选择工作流分享用的 ZIP 文件。
2. 查看每个有内容的分类，按提供者的说明勾选配套内容。遇到页面或配置冲突时，先核对现有内容，再决定替换还是跳过。分享包里的工作流和页面会运行代码，请只导入来自可信来源的包。
3. 点 **导入所选内容**。如果安装了页面或导入后提示重新加载，点击通用设置里的 **保存并重新加载整个应用**。
4. 返回 **首页**，在「工作流版本」卡片里选中与配置页配套的版本。导入后仍需手动选择要使用的版本。

通过 **通用设置 → 分享** 打开导入或导出窗口，在「页面配置」中展开支持分组分享的页面。导出时只勾选要分享的分组，例如镜牢的「饰品配置」和「主题包」。导入时点分组查看变化，再勾选所需分组。分享包包含的饰品、主题包偏好按条目更新，包里缺少的条目保留本机值。星光启用名单和楼层饰品减益顺序按分享包里的名单更新。若涉及覆盖，导入前会统一确认。旧的整页配置包仍按整页导入。

## 开始、暂停和停止

1. 打开游戏，确保游戏窗口可见、处于前台。按工作流提供者的说明，先进入任务要求的起始画面。
2. 在 **首页** 勾选要执行的任务。有次数输入框的任务可以设置执行次数。需要调整队伍等选项时，先打开该任务对应的配置页。
3. 点击 **开始运行**。运行期间尽量让 LALC 操作游戏窗口。
4. 想临时接管时，按 **Ctrl + Alt + P** 或点 **暂停**。操作完成后点 **恢复** 继续。本次不再继续时点 **停止**，等界面提示停止完成后再开始下一次。

直接在游戏里点击、滚动或按键接管时，程序会释放自己持有的输入，等键盘和鼠标连续空闲 10 秒再尝试恢复。等待期间的键鼠活动会重新计时，等待没有总时限。恢复前会刷新画面并检查当前步骤的前置条件。检查失败时，请处理游戏状态后手动恢复。

如果滚轮动作发现光标偏离目标，会停止发送滚轮，从发现偏差时开始等键鼠连续空闲 10 秒，再尝试重新进入当前步骤。

点「开始运行」后，程序先监听键鼠，再尝试立即置前。启动后如果有新键鼠活动，就等连续空闲 10 秒再尝试。运行途中每次发现游戏失焦，都重新开始等待 10 秒。期间有键鼠活动，就从最后一次活动重新计时，包括远程工具转发到当前 Windows 会话的输入。只要目标窗口仍然有效，系统暂时未把它置前时就继续等待。手动把游戏切回前台也能结束普通失焦等待。

首页提示「与已加载的配置页没有匹配任务」时，检查选中的工作流版本、配套页面是否已导入，以及导入后是否已重新加载应用。

## Agent 和 pi 是什么

- **Agent** 是可选的 AI 助手。运行中的步骤出错时，LALC 会先尝试工作流已有的恢复办法。满足自动修复条件时，User Agent 可以分析失败并尝试修复工作流。修复有可能失败，结果会显示在运行记录里。
- **pi** 是 LALC 用来连接模型并运行 Agent 的程序。模型服务负责分析和回答。即使安装包自带 pi，也需要配置一个可用的模型服务。

### 如何开启 AI 修复

使用 `without-agent` 包时，先从 [pi 1.5.0 发布页][pi-release] 下载 `pi-windows-x64.zip` 并解压。在 Windows 开始菜单搜索「编辑账户的环境变量」，编辑 [Path][path]，添加 `pi.exe` 所在文件夹，点击确认，再重新打开 LALC。

在 **通用设置 → User Agent** 打开「启用 User Agent」，选择服务并填写所需信息。

| 模型服务 | 需要填写 |
| --- | --- |
| [DeepSeek][deepseek] | 输入从 DeepSeek 开放平台取得的 [API Key][deepseek]，也就是访问模型服务的密钥。程序预设服务地址和 `deepseek-flash` 模型。 |
| [llama.cpp][llama] | 先启动自己的模型服务，填写完整服务地址（例如 `http://localhost:12138/v1`）和支持图片的模型名称。服务要求认证时，再填写密钥。 |

点 **测试连接** 检查设置。

API Key 通过「设置」弹窗输入，点「保存」后生效。取消、关闭或留空会保留现有密钥。需要移除密钥时，点「清空」。

启用后如果首页提示配置不完整，可以补齐设置，或先关闭 User Agent，再运行已有工作流。使用外部模型服务时，修复请求可能会发送相关游戏截图和工作流内容，并按服务商规则计费。

## 查看记录和反馈问题

运行出错时，打开左侧 **运行记录**，选择对应时间的记录，查看失败步骤、错误详情及可用的截图。向工作流提供者或本项目反馈时，可以附上程序包版本、选中的工作流版本、所处的游戏画面和相关错误。分享日志或截图前，先检查是否包含账号信息或本机路径。

本机和导入日志的右侧详情默认收起。点「展开详情」可看开始时间、已记录的基础 Manifest 和可确认的最终 Manifest。导入日志还会显示来源的 **原 Run ID**。「复制详情」可直接复制这些信息，「复制 Run ID」可将导入副本的查询编号交给 Agent。导入与本机执行共用递增序列，仅查看本机日志时可能会看到跳号。

如果你要把工作流分享给别人，可从 **通用设置 → 分享 → 导出…** 选择工作流版本、所需素材及配套页面。默认 ZIP 文件名带有精确到毫秒的本地导出时间。页面配置是单独的选项，只有希望一起分享的设置才需要勾选。

如果你有想让 Agent 协助主动更改工作流，或者配置页面，可以打开开发者面板和 Agent 聊聊，记得配好 api key～
