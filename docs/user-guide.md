# LALC 用户指南

LALC 可以在 Windows 上按预先编写的工作流操作《边狱公司》。每个工作流负责一组特定任务。第一次使用时，你需要准备 Windows 程序包，以及与你要运行的任务配套的分享包。

## 解压并打开

1. 把下载的 Windows x64 压缩包**全部解压**到一个文件夹。
2. 在解压后的文件夹里双击 **LALC.exe**。以后更新程序时，用户设置和运行记录仍存放在独立的 `%LOCALAPPDATA%\LALC` 目录。
3. 如需切换语言，打开 **通用设置 → 界面语言**，选择「简体中文」，再点「保存并重新加载整个应用」。

文件名含 `with-agent` 的包自带运行 [Agent（AI 助手）][agent] 所需的 [pi][pi] 程序。只运行已有工作流时，选任一压缩包即可，也可以关闭「启用 User Agent」。准备使用 AI 修复时，选 `with-agent` 可以省去手动安装 pi 的步骤，模型服务仍需单独配置。

## 导入工作流

程序压缩包提供 LALC 本身。首页一开始没有可运行的任务时，请向工作流提供者获取配套分享包。一个任务可能需要同时安装工作流版本、识别游戏画面的图片，以及用于配置任务的页面。

1. 打开 **通用设置 → 分享 → 导入…**，选择工作流分享用的 ZIP 文件。
2. 查看每个有内容的分类，按提供者的说明勾选配套内容。遇到页面或配置冲突时，先核对现有内容，再决定替换还是跳过。分享包里的工作流和页面会运行代码，请只导入来自可信来源的包。
3. 点 **导入所选内容**。如果安装了页面或导入后提示重新加载，点击通用设置里的 **保存并重新加载整个应用**。
4. 返回 **首页**，在「工作流版本」卡片里选中与配置页配套的版本。导入后仍需手动选择要使用的版本。

## 开始、暂停和停止

1. 打开游戏，确保游戏窗口可见、处于前台。按工作流提供者的说明，先进入任务要求的起始画面。
2. 在 **首页** 勾选要执行的任务。有次数输入框的任务可以设置执行次数。需要调整队伍等选项时，先打开该任务对应的配置页。
3. 点击 **开始运行**。运行期间尽量让 LALC 操作游戏窗口。
4. 想临时接管时，按 **Ctrl + Alt + P** 或点 **暂停**。操作完成后点 **恢复** 继续。本次不再继续时点 **停止**，等界面提示停止完成后再开始下一次。

首页提示「与已加载的配置页没有匹配任务」时，检查选中的工作流版本、配套页面是否已导入，以及导入后是否已重新加载应用。

## Agent 和 pi 是什么

- **Agent** 是可选的 AI 助手。运行中的步骤出错时，LALC 会先尝试工作流已有的恢复办法。满足自动修复条件时，User Agent 可以分析失败并尝试修复工作流。修复有可能失败，结果会显示在运行记录里。
- **pi** 是 LALC 用来连接模型并运行 Agent 的程序。模型服务负责分析和回答。即使安装包自带 pi，也需要配置一个可用的模型服务。

### 如何开启 AI 修复

使用 `without-agent` 包时，先从 [pi 1.5.0 发布页][pi-release] 下载 `pi-windows-x64.zip` 并解压。在 Windows 开始菜单搜索「编辑账户的环境变量」，编辑 [Path][path]，添加 `pi.exe` 所在文件夹，点击确认，再重新打开 LALC。

在 **通用设置 → User Agent** 打开「启用 User Agent」，选择服务并填写所需信息。

| 模型服务 | 需要填写 |
| --- | --- |
| [DeepSeek][deepseek] | 输入从 DeepSeek 开放平台取得的 [API Key][deepseek]，也就是访问模型服务的密钥。程序预设服务地址和 `deepseek-flash` 模型。 |
| [llama.cpp][llama] | 先启动自己的模型服务，填写完整服务地址（例如 `http://localhost:12138/v1`）和支持图片的模型名称。服务要求认证时，再填写密钥。 |

点 **测试连接** 检查设置。

启用后如果首页提示配置不完整，可以补齐设置，或先关闭 User Agent，再运行已有工作流。使用外部模型服务时，修复请求可能会发送相关游戏截图和工作流内容，并按服务商规则计费。

## 查看记录和反馈问题

运行出错时，打开左侧 **运行记录**，选择对应时间的记录，查看失败步骤、错误详情及可用的截图。向工作流提供者或本项目反馈时，可以附上程序包版本、选中的工作流版本、所处的游戏画面和相关错误。分享日志或截图前，先检查是否包含账号信息或本机路径。

如果你要把工作流分享给别人，可从 **通用设置 → 分享 → 导出…** 选择工作流版本、所需素材及配套页面。页面配置是单独的选项，只有希望一起分享的设置才需要勾选。
