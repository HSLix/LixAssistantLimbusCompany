# Stage 3 scope moved

ADR 0025 replaces the former Stage 3 runtime scope with [Stage 3 — Agent-assisted Component Repair](stage-3-agent-assisted-component-repair.md).

The complete former runtime recovery, supervision, Asset creation, multi-Component maintenance, and related discussion TODOs are retained under [Stage 3.5 — Agent Runtime Step Recovery and Maintenance](stage-3.5-agent-runtime-step-recovery-and-maintenance.md). This compatibility link does not define a separate implementation requirement.
