# 镜牢饰品图鉴同步影响审查

## 已接受的变化

- 饰品名称由英、中、日槽位迁为默认标签加任意数量的普通标签。旧配置沿用原固定 ID，非空的英、中、日名称进入普通标签。跨饰品重复标签在编辑时拦截，同一条目内部重复标签自动合并。
- 已学习饰品的默认标签来自 Asset 逻辑名末段。编辑会先预览合法目录名，再同步素材目录和图鉴引用。固定 ID 与图片哈希保留。中文等名称可作为普通标签。
- 静态索引随页面带上原来的 332 个 ID、流派及名称。页面只从共享 Asset 读取饰品图片，尚未学习的条目显示名称和流派。主题包沿用其现有页面图片和名称规则。
- 自动收录和旧图补录由 `maintain` 完成，提交成功后同一次 Run 可读取。配置页再次显示或点击「刷新图鉴」时读取最新收录，按收录时间倒序展示。

## 已确认的影响

| 位置 | 原行为与完成的调整 |
| --- | --- |
| `ShopGiftsPage` | 旧页读取静态图片和语言键。升级页用固定 ID 合并旧表单、静态条目和实时图鉴。支持输入多个名称、预览目录、显示中文流派和读取 Asset 缩略图。 |
| `step.mirror_sell_gift_slot`、`sub_workflow.mirror_sell_gift_maintain` | 旧流程保存图片，命中旧素材就跳过。现在填写图鉴资源 `mirror.settings/gift-catalog`，命中未登记素材时用匹配返回的完整哈希补录。演练沿用只读行为。 |
| `step.mirror_shop_gift_pick._catalog` / `_name_match` | 原来只读 Run 启动快照。现在叠加实时图鉴，并使用默认标签和普通标签识别同一 ID。归一化统一全半角、大小写、空格与标点，保留多语言字母。同一匹配档位跨 ID 并列时记录 warning 并跳过。 |
| `PageContext.read_asset_image` / `commit_resource_json` | 原来页面只读包内图片。新增按逻辑名及完整哈希读取 Asset，预览保持与现场隔离。页面编辑取得现有游戏活动锁，复核资源版本。素材改名限制在同组，目标已存在时拒绝覆盖。JSON 写入异常时回退目录。 |
| 分享与部署 | 页面包可以覆盖导入原 `mirror.py`，沿用 `mirror.settings`。页面和 Workflow 打成一个包，Host 需包含新 PageContext 方法。包只带页面、Workflow 和原有页面资源，活动 Asset 与图鉴记录保存在本机。 |

通用页面图片存储需要新图片资源及其生命周期。镜牢专用 Action 需要由应用承载饰品和主题包规则。当前使用既有裁剪、匹配与页面 JSON Action，Host 只增加通用的图片读取和编辑提交接口。后续主题包可以沿用该接口。

## 验证与边界

- 普通回归覆盖共享页面资源、Asset、Sharing 与 Action 类型声明。新增测试确认改名前后图片哈希、标签、旧版本拒绝、运行互斥、目标冲突和写入失败回滚。
- 通过真实 Sharing 解析及导入路径，在隔离数据目录完成页面和 Workflow 的升级。回放覆盖 332 项旧图鉴、语言标签迁移、中文流派、Asset-only 饰品图片、旧素材补录、无写入演练、新饰品学习、改名和同次运行按多个标签命中。
- 现场学习和购买的最终验证需在 Windows 真游戏完成。本地未更改用户安装、Default Manifest 或共享活动素材。
- 目录改名和图鉴保存跨两个文件系统对象。普通调用异常可回滚。进程在两步之间被强制终止时，需要检查素材目录与图鉴引用。历史日志仍记录原来的逻辑名。
- 个体购买名单仍按先前决定应使用固定 ID。本次把名称匹配解析到 ID，并沿用当前商店的购买流派规则。

## 饰品图片候选和详情布局

- 左侧列表显示代表图、名称、流派和图片状态。名称标签与流派筛选可与「只看图片异常」合用。页面按图鉴标签直接定位 `mirror/gift` 下的目录，有图即能显示，缺少 Workflow 登记也适用。登记图缺失时会预览目录内其他有效图片。
- 宽窗口在右侧显示详情，窄窗口点选条目后打开详情。详情加载并检查全部候选，支持切换和放大，候选切换不写入图鉴。候选数取同一 Asset 目录的图片文件，已发现无法读取的文件从可预览候选中排除并另报异常。
- 页面包沿用已重新合并的 Workflow 对象。打包检查对照 Workflow ID 和每个清单文件的完整哈希。
