# 常见问题（FAQ）

安装 LALC、导入资源包和配置 Agent 的具体步骤，请参阅[用户指南](user-guide.md)。

## 运行 LALC 一定要开 Agent 吗？会一直花模型费用吗？

Agent 是可选的。关闭 User Agent 或使用不带 Agent 的安装包，照样可以运行已有工作流。即使启用了 User Agent，工作流正常运行时也不会调用模型。遇到故障时，LALC 会先用工作流自带的恢复办法。只有工作流自己处理不了、又满足自动修复条件时，才会请 User Agent 尝试修复。

成功的修复成果可以在后续运行中复用。这个设计就是为了少调用 Agent，尽量省下模型费用。

官方资源包可以独立于程序更新。你可以在首页「版本与更新」里下载并预览新版，选择需要的工作流和配套资源再导入，也可以从 GitHub Release 手动下载资源包。[用户指南 · 更新程序](user-guide.md#更新程序)

## 能用 Agent 改工作流和配置页面吗？做好的资源包可以投稿吗？

可以。在开发者面板里，你可以主动告诉 Agent 想自动执行哪些操作、希望任务怎么跑，以及配置页面需要提供哪些选项，让它协助编写或修改。现在默认资源包里的工作流和配置页面，也是我用这种方式和 Agent 一起做出来的。[用户指南 · 开发者面板](user-guide.md#开发者面板)

欢迎把 LALC 改成适合自己的样子。做出了顺手的工作流或配置页面，也欢迎从 **通用设置 → 分享 → 导出…** 打包，分享给其他玩家，或者通过 GitHub Issues 或 Discord 向我投稿。我会在更新公告里注明所采用资源包的来源，让大家知道是谁做的。[GitHub Issues](https://github.com/HSLix/LixAssistantLimbusCompany/issues) · [Discord](https://discord.gg/bVzCuBU4bC)

## 为什么镜牢设置里缺了一些饰品和主题包？

这是正常现象。饰品和主题包列表由镜牢模块自行维护（不依赖 Agent），运行时会把识别到的新条目补进列表。多跑几轮镜牢，遇到的饰品和主题包多了，配置列表也会逐渐补齐。

## 默认资源包支持镜牢困难模式吗？

截至 6.0.0，默认资源包暂不支持镜牢困难模式。陆爻齐还没抽出时间推剧情，困难模式还没解锁。
