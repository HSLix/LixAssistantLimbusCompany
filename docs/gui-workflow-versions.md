# 工作流版本选择改进

2026-11-08：用户逐项确认并授权实现；本记录替代 [User GUI P0](user-gui-p0-layout.md) 中的版本选择表现和对应中文文案，不改变执行、批准或默认版本的权限语义。

## 接受的设计

- 中文 GUI 将 Manifest 称为“工作流版本”；“开始运行 Plan”改为“开始运行”。代码标识、UUID 与文件名保持原样。
- 2026-11-08 紧凑布局修订（替代本记录原完整 UUID、秒级时间及空说明占位）：标题右侧为“版本历史…”；当前默认版本仅一行显示前 8 位 UUID 和本地分钟级发布时间。完整 UUID 可悬停查看，不在 Dashboard 常显。
- 仅默认版本与最新版本不同时显示浅背景更新提示，短 UUID、分钟级发布时间与右侧紧凑“使用最新”按钮横向排列；已是最新时整块隐藏。说明为空时不占位，有说明时最多单行省略，悬停查看全文。
- 历史使用独立对话框，按发布时间倒序，分别标记当前与最新（同一项可同时标记）；预选当前，选择其他项后启用“设为默认版本”。选中项的完整 UUID 与完整说明放在固定高度、可滚动详情区；取消不更新默认版本。切换失败保留对话框并经原错误入口报告。
- 最新版本是所有本地留存版本中时间最新的一项；每两秒检查一次。当它与默认版本不同时自动显示卡片，只有点击才切换默认版本，正在运行的任务保持原版本。历史版本仍可显式选择。
- 候选 manifest.json 新增可选字符串 AdditionalMessage；发布保存说明并生成固定的带时区 published_at。存储保留亚秒精度用于排序，界面显示到秒。旧文件缺省说明为空、时间回退文件修改时间；导入保留原发布时间。说明随已发布版本保持不可变，不新增 GUI 编辑框。
- 次数框采用左减、中间数字、右加，保留 1–2147483647 范围与数字输入，预留完整数字宽度；到达边界禁用对应按钮；任务名和整组次数/设置控件在窄窗口自动换行，避免相互挤压。页面模块可声明布尔 `SHOW_TASK_COUNT`，默认 `True`。为 `False` 时隐藏整组数字与加减，保留勾选和设置；启用传 1、禁用传 0，保留旧次数但不使用。参数仅影响该页注册的任务，纯设置页无次数控件。

## 实施前影响审查

已确认：gui.py 原版本选择器只展示 UUID；manifest.py 以文件修改时间排序、严格限制顶层字段，并在发布与候选初始化时只复制组件映射。manifest_reference.py 也严格限制顶层字段。因此只改界面会丢失说明，或使新版本无法被开发工具引用。

调用路径：候选 → ManifestManager._prepare → publish → list_manifests / load → UserGUI；候选初始化须保留说明；Sharing 经 _prepare 规范化后导出与导入，须保留新元数据；ManifestReference.read 须接受并检查新字段。校验仍拒绝未知字段及错误字段类型，不修改旧文件。

实施包括上述路径、中文 .ts/.qm 资源、领域术语与开发教程、测试预期及元数据／卡片回归。不新增依赖或改变发布与默认选择分离的约定。

潜在风险与边界：旧文件复制或导入后，回退的文件修改时间可能变化；没有真实发布时间时无法重建。轮询读取本地版本列表，超大版本库的性能未作专项验收。
