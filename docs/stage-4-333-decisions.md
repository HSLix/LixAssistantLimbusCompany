# #333 双语与语言重载讨论

2026-10-28：grill-with-docs 已结束，开发者确认以下共同理解，并补充示例页要求；design-impact-review 随后获开发者确认并授权实施，当前本地结果见[实施记录](stage-4-333-implementation.md)。

## 已确认

- 翻译覆盖 User GUI 与 Developer GUI 的全部应用自有界面文案，包括导航、设置、运行控制、通知与弹窗；中文模式以中文为主，英文模式的应用自有文案全部英文。
- 原始异常、Trace、模型回答及用户内容保留原文。外置 Business Settings Page 由宿主提供最小语言接口，页面作者负责翻译，不自动翻译任意页面内容。
- 用户建议考虑官方 FluentTranslator 与应用 QTranslator 组合；具体接入方式待核对官方资料及影响审查。
- 语言选择变更后立即保存，并提示重启后生效；由用户点击现有“保存并重新加载整个应用”入口统一重启两窗口，不自动重启。当前进程固定使用启动时确定的语言，后续新弹窗也不提前切换。活动期间允许保存语言选择，但禁止重载。
- 外置页接口提供本次生效的语言与最小翻译能力，并支持导航名称翻译；项目自带示例完整双语。已有外置页保持兼容，缺少翻译时保留原文，不拒绝加载、不调用模型翻译。应用及自带示例承担英文模式全英文要求，第三方页面由作者负责。页面 ID、任务 ID 及已保存配置不随语言改变。
- GUI 语言是 User/Developer 两窗口共享的应用设置，但设置入口仅位于 User GUI 的 General Settings；Developer 不新增语言设置或重载入口，单独启动时沿用共享语言选择。
- 开发者确认优先采用 FluentTranslator 配合应用 QTranslator；默认跟随系统，中文系统用简体中文，其余用英文；GUI 语言不改变游戏识别语言。
- `example/pages/` 现有示例更新为支持语言切换，另增一个不支持语言切换的页面，明确演示兼容与原文回退。该兼容示例是英文模式全英文要求的显式例外，不由宿主自动翻译。
- 影响审查期间开发者明确：错误详情无需中英分开，可保留原文或中英混合；语言覆盖重点是 GUI 组件（标题、按钮、导航、标签、提示等），不将诊断详情翻译纳入本票。
