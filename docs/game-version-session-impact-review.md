# 游戏版本与 Agent 历史关联：影响审查

2026-11-01。依据[逐项确认记录](game-version-session-decisions.md)的 15 项已确认决定及当前工作区源码；本报告为实施前审查，整体方案及下述实施收口已获开发者明确“同意”确认，授权实施。未修改产品代码、运行模型或执行 Windows 构建。工作区已有其他未提交改动，实施须保留。

## 设计变化

- 新增每轮游戏版本观测，以 `(game_version, steam_build_id)` 组合关联轮次及 Session；只更新当前组合最近观测时间，不改历史组合。
- 观测持久追加到本轮日志及用户消息 runtime_context，恢复原样历史，不重写旧消息 / 系统提示词，不承诺零 cache miss。
- GUI Construct / Repair、CLI Repair、GUI 连接 / 模型诊断及现有独立错误诊断日志纳入；后者在日志开始时观测一次。不提前实现 Runtime。
- 新增三个跨入口只读历史工具；版本筛选是定位线索，不是同一 Session 其他轮次的读取限制。每轮及图片注明版本组，无关联显示 Unknown。
- 无观测的旧历史不扫描导入。已有 Session 的新轮次可进入索引，按需读取同一 Session 旧轮次时仅展示 Unknown，不创建旧轮次观测。
- 删除独立 `lalc pi-probe`，保留其共享启动 / RPC / 扩展能力及必要测试；不为已删除入口补日志。

## 实施收口建议

### 观测与定位

- 新增独立的只读观测模块；Steam VDF 解析须处理引号、反斜线及多库结构，验证 appid 1973530、安装清单 install 目录与路径边界，不导入游戏代码。
- 已保存 Steam 客户端根有效则使用；失效后按确认顺序发现候选，去重后验证，歧义报错。缓存仅在成功定位且至少一个 ID 读取成功后保存；人工设置写同一位置，失败不覆盖旧有效值。
- 游戏版本与 Build ID 独立采集；一个失败不丢弃另一个。两者都空才是索引 Unknown 组。UTC observed_at 为本轮实际观测时刻；非 Windows 正常返回不可用诊断，不探测 Windows 盘、不影响对话。
- 完整解析优先；4 字节例外绑定已验证 Unity 6000.3.12f1、序列化 / PlayerSettings 类型树布局及解析器版本，不能只看剩余长度。保留产品身份与版本格式校验，异常原样分类记录，不字符串搜索猜测。
- 发现失败提示 User GUI Steam 路径入口，正常版本获取失败只记现有日志 / 状态，不每轮弹出阻塞对话框。目录不存在、权限、解析器缺失 / 不兼容分别可诊断。

### 持久化与索引

- 每轮保存一个自包含观测记录，含两个 ID、UTC 时间、来源类别及字段错误；开发轮次的 runtime_context 使用同一份观测，不重复探测。同一轮工具 / 预检 / 格式纠正不创建新观测。
- 数据目录采用一个 SQLite 索引文件，使用标准库 sqlite3，不引入数据库依赖。以日志 UUID + 轮次去重，保存数据目录内相对日志定位；通过查询计算去重 Session 数量及组合最近观测时间，避免多个重复可变统计副本。
- SQLite 事务处理跨 GUI / CLI / 诊断并发，短时有界等待，不持有数据库锁执行模型或文件扫描。先写日志事实，再提交索引；索引错误只记诊断，不回滚已发生的 Agent 操作。
- 索引丢失 / 损坏时不自动创建“看起来完整”的空历史。查询明确不可用并提示显式 CLI 重建；重建仅提取已保存观测，不推断旧版本，不迁移旧日志。重建在临时数据库完成并原子替换，失败保留旧文件，使用与普通写入一致的跨进程协调，避免丢失并发新增观测。
- SQLite 使用 rollback journal，稳定状态为一个数据库文件，写入期间允许 SQLite 自身的临时事务文件；不手写多进程读改写 JSON 索引。

### 三个工具与显示

- `list_game_versions`：分页列组合、去重 Session 数及最近观测时间，可按来源类别筛选；游戏版本优先显示，缺失时显示 Build ID，两者缺失显示 Unknown。
- `search_agent_sessions`：按完整组合、单一版本字段或 Unknown 筛选，返回去重 UUID、标题、来源、匹配轮次及该组合最近时间；标题是已有首条用户文字规则，诊断使用操作名称，不额外请求模型。
- `read_agent_session`：显式 UUID 与轮次 / 匹配版本筛选，按事件分页且限制返回字节；列出后续分页位置及图片引用。显式图片请求只返回该 Session / 轮次实际引用、经路径和哈希校验的内容，并携带版本组。
- 不静默截断超长单事件，返回可继续读取的片段位置；不把历史用户 / 工具文本当成新指令，不恢复或执行所读 Session。损坏、清理、路径越界、符号链接和缺失图片明确报错，不借版本索引授权读取任意文件。
- 当前活跃日志可能正在追加；读取只使用完整记录，末尾未完整记录报告未完成，不修改原日志。并发读取不得调用 DeveloperSession.restore，不争抢当前轮已持有的 Candidate 锁造成自读死锁。

上述索引文件格式、分页及工具名属于具体实施选择；不增加语义搜索、自动摘要、记忆有效性判定或新 GUI 历史浏览器。
