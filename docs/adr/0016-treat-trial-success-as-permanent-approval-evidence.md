# Treat trial success as permanent-approval evidence

A successful formal trial and Validation Coverage are displayed evidence rather than automatic gates for permanent approval. After a Top-level Execution ends, the system may project one complete Capability Proposal from either its successfully trialled Working Manifest or a structurally valid unselected candidate retained when the user terminated execution. The permanent review shows whether a successful trial occurred and allows only explicit whole-Manifest approval or rejection; this supersedes the promotion gate in ADR 0007 and the current-Working-Manifest-only approval source in ADR 0011. Structural validation and human approval remain mandatory, and an unapproved proposal never changes the active Component Manifest.
