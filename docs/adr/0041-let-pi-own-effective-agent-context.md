# 由 pi 保存有效 Agent 上下文

2026-11-12，开发者已确认。Developer Session 的有效模型历史、文字摘要、保留边界和图片上下文编辑统一持久化为 pi Session；LALC 继续拥有 Candidate、当前入口权限、完整脱敏业务日志和原始图片证据。替代 ADR 0038 所用的每轮新建 pi 会话并注入完整历史的恢复方式；保留进程按需复用、每轮刷新权限、中途失败不重放工具等边界。ADR 0033 的无损日志留存继续有效，模型上下文裁剪是本次新增行为。

LALC 扩展在新用户轮次和工具循环安全边界计算产品预算，通过 pi 的 SessionManager／boundary drafts 保存唯一有效压缩结果，不在宿主维护第二套摘要边界。比例／固定目标约束包含系统、工具、图片的总量，不能直接等同 pi 的 keepRecentTokens；为实现这一语义使用自定义总结策略，关闭另一套原生阈值／溢出重试，避免重复压缩。系统提示、当前工具声明不摘要，权限由当前入口重新确定，历史及摘要均不是授权。

用户确认的参数、迁移和异常策略见[影响审查](../context-compaction-impact-review.md)。已有可恢复 Session 首次继续时自动迁入；原始证据不重写。pi 文件属于私有执行状态，不直接进入只读 Sharing 历史导出。压缩请求单独计数，空／截断／失败摘要不提交成功检查点；原始工具副作用不回放。具体实施及验证见[实施记录](../context-compaction-implementation.md)。
