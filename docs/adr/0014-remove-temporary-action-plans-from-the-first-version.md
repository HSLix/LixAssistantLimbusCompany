# Remove Temporary Action Plans from the first version

The first-version Runtime Agent cannot emit or execute a Temporary Action Plan and has no direct model-action channel. Every Agent Turn returns exactly one Working Manifest Update Proposal, `Request Step Recheck`, or Safe Task Termination recommendation. Executable repair must be a formal compatible replacement of the current paused Step and pass the ordinary Loader contract; an Asset-only repair may retain the existing Step identity. Either form enters through a reversible Working Manifest switch and receives an immediate legal formal trial of the resulting current Step.

This removes the Temporary Plan Adapter, `plan_id`, plan-specific AST contract, plan timeout, plan execution Trace, and independent one-off Agent Python runner from the first version. It narrows the endpoint model's task to modifying existing structured automation instead of exploring and self-validating temporary behavior. Unapproved formal candidate Python remains non-sandboxed and requires Supervised review and confirmation before every runtime trial; permanent registration remains separately human-approved.
