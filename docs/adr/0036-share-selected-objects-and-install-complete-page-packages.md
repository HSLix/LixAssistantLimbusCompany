# Share selected objects and install complete page packages

Sharing uses an explicit selection of Workflows, independent Asset groups, complete page packages and read-only Agent history. We deliberately avoid Workflow-to-Asset inference and privacy scanning: the caller selects Asset groups and reviews a persistent privacy warning. Imported Manifests never overwrite an occupied UUID; a collision receives a newly allocated, explicitly confirmed identity, preserving the local UUID-to-content mapping and Default. External Agent history retains evidence without Session authority or replay.

A page owns its source and resource directory, and review approval and replacement refer to the complete package. This replaces ADR 0034's single-file boundary, rather than embedding images in source or maintaining a shared page-resource lifecycle. Existing single-file pages and drafts remain readable; copying/export wraps them and installation converts them without a bulk migration. Private configuration stays outside the package, and all page tools, preview logs and loaders observe this boundary.

Sharing Review approves a fixed package for deferred unified submission; an explicit additional confirmation may install selected unreviewed pages with runtime checks unproven. This exception applies only to the human Sharing flow: Agent installation still requires its dedicated human approval. Import does not execute structural validators or automatically activate pages or Workflows. Per-object replacement protects the previous object on ordinary failure; cross-object rollback and crash recovery are outside the accepted scope. See the [final Sharing contract](../sharing.md) and [accepted discussion](../sharing-decisions.md).

2026-11-09 refinement: export selection goes directly to the ZIP save dialog, without a file-review step. Working snapshots and pending output files use ordinary creation with inherited parent permissions, retaining cleanup, integrity checks, locks and rollback. Import Page Review is unchanged.
