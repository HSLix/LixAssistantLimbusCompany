# 使用完整参考版本与按需复用的 Agent 进程

2026-11-05，设计已确认并本地接入，验收边界见实施记录。外部知识库保留字面搜索并新增混合代码搜索，以独立参考版本绑定文件与索引。保留可用 A，在额外副本中完成 B 的 fetch、确定 upstream 提交后的 reset 与建索引，全部成功后才切换；失败继续 A，向 Agent／调用方报告并记录日志。更新前检查实际目标盘的副本与临时空间需求，空间不足或构建中耗尽同样失败；首次没有索引时保留字面搜索和读取。接受额外磁盘与复制开销，避免复杂的原地回滚；各仓库独立更新。此项替代 ADR 0034 中 fetch 不更新工作区的限定同步规则，其他权限边界保持。

pi 和 LALC 专用 codesearch 首次需要时启动、跨轮复用、宿主退出关闭，不绑定开发窗口；复用前发现失效可重建，执行途中 pi 退出则结束本轮、不重放工具。进程存活不保留旧轮权限，历史／设置／额度仍逐轮明确配置。优先最少的清晰所有权与按需检查，不引入保活、周期监控或通用服务框架；未来 Runtime 复用不构成本次工具授权。

同时构建自带 Agent 功能包与精简包；自带包含 pi、codesearch 和默认量化 MiniLM，精简包仍支持外部资源；普通使用不自动下载。首版聚焦搜索与读取，不接入符号影响分析或参考项目执行。工具命名、错误边界及证据见[设计确认](../external-code-search-decisions.md)、[验证报告](../external-code-search-validation.md)和[影响审查](../external-code-search-design-impact-review.md)。
