# Deduplicate Agent logs with conversation-local references

2026-10-28：一次约 217 MB 的 Agent 交互留存主要由图片和累计历史重复写入产生。开发者确认完整保留脱敏后的请求、回答、工具结果、图片和事件身份/顺序，通过对话内内容引用减重，不以摘要或删减代替原始信息；实际发给模型的历史、图片字节/顺序及请求额度不变。每个对话目录自包含，复制即可完整展开，不跨对话共享内容库；旧日志不迁移、不重写，本次不新增历史加载/展示界面或通用旧格式兼容框架。

新日志以 log-format.json 标记格式，重复大块文本/结构存于本对话 objects/，图片引用本对话已留存的原始图片（没有现成图片时保留哈希二进制内容）。引用含对话内相对路径、SHA-256 和编码类型；保留 JSON 消息顺序及字符串内容，对与引用标记冲突的用户字段做显式转义。先完成内容保存，再写引用；读取需校验路径边界和哈希，缺失、损坏或无效引用明确失败，不悄悄返回残缺内容。原有 PNG 证据、源码快照和 Diff 的普通文件布局继续保留。

持久化与实时消费分开：pi 请求快照先经过临时传输文件交给 Python 宿主去重，工具结果为 pi 提供完整的临时 JSON，GUI 回调也继续接收完整事件；临时文件不属于长期日志，随轮次清理。预检和正式处理共用固定的对话内容根目录，即使当前事件目录临时切换到 round-N 也不另建内容库。诊断可按需展开新格式的单个 JSON/JSONL 文件，不同时保存一套完整副本；旧日志保持普通文件原样。

本决定只改变日志存储表示，不调整预检触发、模型上下文裁剪、试运行理由/权限、运行时 Agent Policy 或日志保留时长；后续改动另行评估。
