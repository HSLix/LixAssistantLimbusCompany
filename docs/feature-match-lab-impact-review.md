# SIFT 特征匹配调试：实施前影响审查

2026-11-14；实施前部分基于源码静态检查。
设计来源：[讨论记录](feature-match-lab-decisions.md)。开发者已确认最终设计并授权实施；实施与验证见文末。

## 设计变化

- 识别调试页新增 SIFT 标签，与模板匹配、OCR 共用固定原始截图，独立保存选区、参数和结果。
- 使用现有 Asset 模板；单图或逻辑名整组尝试多目标查找，按内点数量降序排列。
- 默认灰度、三倍线性放大、CLAHE（clipLimit=2、tileGridSize=4×4）；只处理工作副本。
- 参数与门槛见讨论记录。不增加 Trusted Action、Agent 工具、依赖或持久化数据迁移。

## 多目标算法边界与最终确认提案

- 全图或选区内查找多个实例，不预设业务候选区域或节点坐标。
- 从截图特征向模板特征配对，保留不同目标对同一模板特征的匹配；不能使用只为每个模板特征保留一个截图配对的单目标策略。
- 迭代提取几何模型，剔除已解释的配对后继续查找；对退化、非有限、翻折或越界投影拒绝返回目标，循环必须有限推进。
- 每个候选单独计算比例：几何内点数 / 落在该候选投影范围内的初筛配对数；不把其他位置目标的配对算作本目标的外点。内点计数需消除重复配对，防止重复特征膨胀证据。
- 默认几何误差容差为原图 4/3 像素，与参考实验三倍图上的 4 像素一致；随放大倍数换算。
- 结果用原图中的外接矩形展示，整组模板全部处理后统一按内点数排序、应用可关闭 NMS；同分按位置和模板身份稳定排序。
- 无特征、配对不足或几何验证未通过，正常显示无匹配；非法参数、坏素材和执行异常明确报错，清当前方式结果，保留截图与选区。

## 潜在风险

- 多目标相同描述子会使单目标模板向截图的最近邻比率测试失效；反向配对与逐实例几何提取必须用重复目标的真实算法测试验证。
- “查找所有目标”是操作目标，不能保证视觉算法零漏检；重复图案、低纹理、遮挡与透视退化可能失败。参考实验不能证明本方案的全图效果。
- 全图三倍放大及无限特征默认值可能明显增加耗时和内存；复用后台互斥，不引入额外并发或隐藏截断结果。
- 灰度关闭不表示获得彩色 SIFT：SIFT 本身基于灰度；关闭显式灰度时，彩色增强须定义清晰并保持模板、截图一致。

## 后续顺序与验证

1. 最终确认上述设计，特别是每候选局部比例、整组无短路及结果展示。
2. 算法与小型真实 OpenCV 检查：多实例、原图与 ROI 坐标、缩放、空白图、退化／误匹配、参数校验、输入不变及重复执行一致性。
3. 后台入口与 GUI，覆盖整组排序／NMS、哈希及活动互斥、独立状态、截图成功／失败、素材与参数失效、忙碌禁用和错误清理。
4. 翻译及 `.qm`、用法和当前状态同步；执行相关默认测试并渲染检查面板。Agent 测试不属于本轮范围。

不新增领域术语：既有 Asset、Trusted Action 和识别调试概念足够；不为可逆调试页扩展新增 ADR。

## 实施与验证

- 已新增 `feature_matching.py`：原图派生预处理、截图向模板配对、按特征方向／尺度预测中心进行空间投票分组，再迭代 RANSAC 多模型提取。分组网格大小由模板尺寸导出，不包含地图布局知识。拒绝退化／翻折／明显越界投影；同一特征位置的重复方向不重复计数。失败模型只剔除其配对，不用被拒绝投影吞掉整片区域。
- 直接对全屏配对做 RANSAC 曾无法检出参考截图的模板问号；空间投票分组后可以检出。分母始终从最初配对计算，避免先前失败迭代改变局部内点比例。
- 已接入 `DeveloperHost.match_feature_preview` 和 `RecognitionPage` 第三个标签；整组全部尝试、统一排序／NMS，沿用活动互斥、路径及哈希验证、不写运行记录。预处理参数、SIFT 与门槛均可调；灰度关闭时增强 Lab 亮度后再提取灰度特征。
- 素材选择与变更清两种匹配结果；调参只清所属结果。切换保留独立选区与结果，新截图成功重置三种方式，失败保留旧状态。无新增依赖、正式 Action、Agent 工具或持久化数据迁移。
- 已同步中文 `.ts`／`.qm`、当前用法及当前状态。一次回归发现新增翻译未写入目录，修复后翻译覆盖检查通过。

### 引用实验截图的额外检查及已知限制

使用引用聊天保留的 1108×602 原图和同样的剑／问号裁剪，全图、默认参数、整组两模板及 NMS，
本机一次后台调用约 **0.538 秒**，返回 **7 个框**，其中包括两个模板来源；这不是“正确 7/8”。
结果包含漏检和定位偏差：例如一处剑候选中心约 `(524,136)`，实际对应节点在 `(555,118)` 附近，外接框明显偏大。
问号全图仅检出模板来源，未检出其他问号。不能将这些框当作已经验证的可靠目标或点击坐标。

局部裁剪与全图的 CLAHE 分块及背景不同；反向多目标配对、去除重复位置等也与旧局部分类实验不同，
所以旧实验准确率不能迁移到本算法。当前功能用于交互调参和收集证据；未来正式 Trusted Action 前仍需补充多截图负样本与定位验收。
