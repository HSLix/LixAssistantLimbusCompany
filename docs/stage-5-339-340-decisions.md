## 已确认

- #339 / #340 合并设计、影响审查、实现和开发者验收；保留两票全部验收项，包括版本绑定、安全安装及重载后 Dashboard / Plan 配置接入，不能仅凭预览通过就认定安装通过。
- 每份 Page Draft 为一个完整 Python 页面文件，沿用现有页面契约，可从空白创建或复制当前正式页，按 Session 持久保存；首版不支持附带资源目录、多文件包或新增依赖。
- 草稿位于 `data_root/developer-sessions/<Session ID>/page-drafts/`，正式页仍位于 `data_root/pages/`，不进入 Candidate 或 Manifest。修改现有页时复制到 Session 并记录原文件名作为安装目标，默认保持 PAGE_ID；新增时确定文件名与 PAGE_ID，安装检查文件名、页面 ID 和 Task ID 冲突，不能误覆盖其他页面。不同 Session 草稿独立，安装对比当前正式页并由人确认覆盖；安装后保留草稿和按稳定 PAGE_ID 保存的旧配置。
- 不实现固定程序的配置兼容检验，不自动调用 submit() 探测兼容，也不增加“检查配置”按钮。宿主检查页面加载、页面契约及必要的路径 / ID 注册边界；两侧仍以旧配置的独立内存副本预览。字段变化、旧配置影响及 Plan 参数使用由 Agent 阅读代码并总结，不能将加载成功报告为兼容性证明。既有破坏兼容方案先获明确授权、安装另行人工确认及不自动清空旧配置的边界保持。
- 已澄清并接受必要检查：沿用 PAGE_ID / PAGE_NAME、可选 TASK_ID、create_page(context) 返回 QWidget 及提供 submit() 方法的页面契约，不调用 submit() 检验配置；安装目标限定在正式 pages 目录，拒绝路径越界、新增误覆盖、其他页面 PAGE_ID / TASK_ID 冲突及宿主保留 ID，正常替换自身 ID 不算冲突。
- Agent 发起对比预览后等待；对比窗口提供“安装此版本”“关闭不安装”“取消本轮”。安装批准绑定实际预览代码，关闭返回未安装并允许 Agent 继续，取消结束当前轮次；不依赖被模态锁住的主窗口按钮解除等待。
- 当前正式页加载失败时在当前侧单独显示错误，仍允许审查并安装成功加载的修复草稿；不得误报为无旧页。拟安装草稿加载失败或不满足页面契约时禁用安装，错误反馈 Agent；两侧错误分别显示。

## 2026-11-02 试用反馈后的修订讨论

本节记录试用后的修订决定。开发者逐项确认以下范围；按其“先 grill、再影响审查、最后实施”的请求完成[修订审查](page-review-tabs-design-impact-review.md)后实施。上文及原实施记录保留历史，冲突处以本节决定为准。

- 已确认：拟安装页加载、页面接口或 ID 注册检查失败，不进入人工审批，直接把具体错误返回同轮 Agent 修正，包括缺少 PAGE_ID、create_page 报错、返回对象不符合页面接口及 ID 冲突。不增加配置兼容检测，不调用 submit()。旧正式页失败仍单独显示错误，允许审批正常修复版。同进程卡死 / 崩溃不在普通异常自动返回保证内。
- 已确认：原双栏审批改成 Current / Proposed / Review 三 Tab，每次打开默认 Proposed。Current 运行当前正式页，缺失显示新增说明、失败显示错误；Proposed 运行已通过检查的草稿；Review 展示 Agent 改动 / 影响总结，并集中呈现文件名、页面 ID、版本哈希等详情。切换 Tab 保留两页各自试填状态，不重新加载。
- 已确认：底部始终保留“安装此版本”“关闭不安装”“取消本轮”；不强制先浏览其他 Tab 才能安装。Tab 切换不改变已绑定的草稿版本、两侧配置独立与关闭丢弃的规则。
