# 特征匹配调试：设计讨论

2026-11-14，开发者已逐项确认，并确认影响审查中的最终设计、授权开始实现。

## 已确认

- 本轮只在开发者识别调试页增加 SIFT 特征匹配方式，暂不注册正式 Trusted Action。
- 能选择现有模板进行试匹配，右侧提供可调参数。
- 默认对模板和截图进行灰度化、三倍放大和增强；增强沿用参考实验的 CLAHE。
- 避免在同一图像上累计预处理；原始截图和模板须保留，每次匹配从原像素生成处理图。
- 查找同一模板的所有目标，结果按匹配分数降序排列；不采用每模板最多一个目标的方案。
- 匹配分数为几何内点数，按其降序排列；同时显示内点比例。默认至少 6 个内点且内点比例不低于 0.5，两项门槛均可调。分数不代表概率，不同模板间不完全可比。
- 预处理可调：灰度默认开启；放大默认 3 倍，可选 1～5 倍；CLAHE 增强默认开启且可关闭。同一组设置同时应用于模板和截图，每次从原像素处理一次。
- 采用完整参数面板：SIFT 特征数上限、尺度层数、对比度阈值、边缘阈值、sigma、精确上采样采用 OpenCV 默认值；匹配开放配对比率（默认 0.75）、原图像素几何误差容差、内点数量及比例，以及 NMS（默认开启、IoU 0.5）。开发者了解配对比率的含义后确认采用。

## 最终确认

- 独立 SIFT 标签，沿用全图／框选交互及独立方式状态。
- 单图或整组查找多个目标；整组尝试全部模板，无优先标签短路。
- 比例按每个候选投影范围内的初筛配对计算，结果按内点数排序并统一 NMS。
- 原图上显示编号框，文本显示内点数、比例、原图坐标和模板身份。
- 已确认[影响审查](feature-match-lab-impact-review.md)中的算法、错误处理与验收边界；查找全部是目标，不承诺视觉算法零漏检。
