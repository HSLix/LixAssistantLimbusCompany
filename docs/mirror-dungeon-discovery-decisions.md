# 镜牢自动收录设计讨论

## 已确认

- Workflow 自动收录现场发现的饰品和主题包。收录结果立即可用，无需第二次观察或人工审核才能启用。
- User GUI 中的发现记录按记录日期倒序展示，方便检查最近的收录结果。
- User GUI 允许修正饰品的多语言名称标签，也允许修正主题包的多语言名称标签。名称标签是各游戏语言下的名称。
- 单件饰品的购买白名单和黑名单绑定图鉴条目的固定 ID。修正名称标签或补充其他语言的名称后，已有名单规则继续适用于同一条目。流派名单仍按流派匹配。

## 静态饰品配置页

首版从 `mirror_ego_gifts/<流派>/<名称>.png` 制作页面包，目录名用作流派键，文件名用作初始英文名称标签。包内图鉴索引保存固定条目 ID，升级页面时已有条目沿用原 ID。用户可按流派和任意语言标签组合筛选，并修正各语言标签。静态素材没有收录日期，列表按当前显示名称排序。

镜牢页沿用 `mirror.settings`。页面提交后，Workflow 从 `ctx.run_state.settings["mirror.settings"]["shop_gifts"]["catalog"]` 取得以固定条目 ID 为键的图鉴。每个条目形如 `{"archetype": 流派键, "labels": {语言键: 名称标签}}`。新版编辑及搜索支持 `en`、`zh`、`ja`。旧版饰品配置保存时删除已有的 `ko` 标签。

名称纠正后条目 ID 不变，图片路径留在页面包内。购买名单、Workflow 购买行为和运行中收录图片留待后续。

## 静态主题包配置页

- 镜牢页新增「主题包」标签。顶部按任意名称标签搜索和按选择偏好筛选，下方用三列卡片展示封面、名称及编辑控件。静态条目按当前显示名称排序。
- 从旧素材目录的 95 张封面建立 91 个条目。4 张中文封面对应已有英文封面，中文名补入同一条目。复刻和原版保留各自的条目。中、英、日名称可独立编辑。
- 每个固定 ID 独立保存一种选择偏好。界面显示「优先选择」「默认选择」「尽量不选」。在 `ctx.run_state.settings["mirror.settings"]["theme_packs"]["catalog"]` 中，每条记录包含 `labels` 和 `preference`。偏好值为 `prefer`、`default`、`avoid`。旧配置没有偏好时使用 `default`。

### 影响审查

- **已确认**：上一版页面的 `ShopGiftsPage` 会恢复并提交韩文标签。移除编辑项之外，还需在恢复时筛除旧值，下一次由 User GUI 的 `submit_pages` 持久保存。饰品图鉴的固定 ID、流派及其余名称保持兼容。
- **已确认**：`sharing.import_selected` 安装整个页面包，页面业务设置由 `PageContext` 按 `PAGE_ID` 单独保存。沿用 `mirror.py` 与 `mirror.settings`，可以升级页面包并读取此前的队伍、商店、轮换及饰品资料。新增的封面和图鉴索引属于页面包。
- **已确认**：`gui.py` 的 `start_plan` 会提交页面并将配置交给 Workflow。本地 Manifest 草稿的 `step.mirror_theme_pack_select.py` 当前按默认坐标选择最左侧卡片。这次实现交付页面和可读取的配置，实战识别及选择策略属于后续 Workflow 工作。
- **验证范围**：通过已有的 Sharing 导入路径升级旧页，验证 91 个条目、筛选、改名后偏好保留、三态保存重开及旧韩文清理。Windows 显示与真实游戏选择需独立验收。
